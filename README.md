# 🌿 Leaf Market

O website aqui desenvolvido, _Leaf Market,_ tem por fim atuar como um mercado e distribuidor de produtos orgânicos. Ele é, primariamente, dividido em duas seções (ou módulos): (a) uma zona administrativa, com separação de acesso através de função; e (b) uma área aberta, na qual os usuários podem visualizar uma variedade de produtos e, caso _logados,_ podem comprá-los.

---

## 🚀 Funcionalidades

- Página inicial com destaque para promoções e produtos orgânicos.
- Catálogo de produtos dinâmico com filtros e categorias.
- Página de detalhes do produto.
- Carrinho de compras (frontend e backend, porém sem o real processamento de dados de pagamento (tais dados são somente armazenados no banco de dados do serviço)).
- Formulário de registro com validação (frontend e backend).
- Sistema básico de login e cadastro de usuários (PHP, sanitização contra injeções SQL).
- Painel administrativo simples para gerenciamento de produtos e funcionários (PHP).
- Responsividade total com Bootstrap.
- Validações com JavaScript (imbutido) e PHP.
